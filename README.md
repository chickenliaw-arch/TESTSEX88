# 性別事件處理流程表 📱 互動式校園性平時限控管資訊網

本專案依據教育部最新發布之 **「校園性別事件通報及調查處理程序參考流程圖（114 年 2 月 3 日修正版 / 202501修）」** 進行視覺化互動設計，專為**智慧型手機（直式版面）**優化，並提供動態期程時限計算、三色狀態長條圖與全文檢索功能。

---

## 🌟 核心特色

1. **手機專用直式版面（Mobile-First Portrait Design）**：
   - 專為直式螢幕打造，單手操作流暢，搭配底部固定導航欄（Bottom Navigation）。
   - 嚴格控制排版字體大小（內文不低於 15px-16px，標題達 24px），清晰易讀、長輩與行動裝置閱讀零負擔。
2. **法定管制期程、人工填入與連鎖推進系統（核心亮點）**：
   - **支援人工填入實際完成日期**：每階段完成後，承辦人員可直接人工輸入「實際完成日」，點擊「✅ 推進下一階段」，系統會**自動將該完成日作為下一階段的法定起算日**，實現環環相扣的流水號時限管制。
   - **雙管考模式自由切換**：
     - 🔗 **階段連鎖推進模式**：可逐一填入完成日並解鎖後續程序，各階段完成後顯示達成徽章，亦可隨時「重新修改」。
     - 📊 **單一基準全推算模式**：以單一起算日平行推算全案各階段之法定期限。
   - **三色動態狀態長條圖**：
     - 🟢 **綠色**：正常進度（安全期間，剩餘時間充足）。
     - 🔵 **藍色**：警示期（進度達 75% 以上或即將屆期，提請專責人員緊盯管制）。
     - 🔴 **紅色**：逾期警報（已逾法定處理時限，啟動醒目紅色警報標籤）。
   - **貼心行政輔助工具**：內建 LocalStorage 本地自動存檔（關閉重開不遺失）、一鍵複製全案公文進度摘要、重設新案按鈕。
3. **即時檢索與分類瀏覽**：
   - 具備即時關鍵字搜尋框與快捷標籤（如：24小時、3天、20天、2個月、申復、教評會、社政通報等）。
   - 支援展開/收合六大程序階段卡片、權責處室分工（學務處、教務處、諮商輔導、教評會、考績會等）。
4. **豐富視覺與 Web Audio 原生音效**：
   - 採用清爽明亮的現代漸層配色（蔚藍、翡翠綠、溫暖琥珀、柔紫）。
   - 內建基於 HTML5 Web Audio API 的原創音效引擎（點擊泡泡音、安全和弦、警示雙音、逾期警告音），**無需加載任何外部 MP3 檔案，離線可用且保證永不失效**，並附右上角音效切換開關。
5. **四大身分快速權益指引與常見 QA**：
   - 包含教職員通報者、當事人/家長、性平會/專責秘書、行為人等四大身分視角重點須知。

## 📅 法定管制期程對照表（依 114 年結案版流程圖）

| 管制期程 | 法定階段 | 權責與處置重點 | 法規依據 |
| :--- | :--- | :--- | :--- |
| **24 小時** | 知悉通報 | 口頭聯繫通報人員，完成校安與法定通報（關懷e起來）。*滿18歲非兒少性騷擾免社政通報* | 性平法第22條 |
| **3 天** | 移送性平會 | 秘書單位接獲申請調查或檢舉後，於 3 日內陳報校長送性平會 | 作業流程圖規定 |
| **7 天** | 管轄權移轉 | 學校無管轄權時（如校長為行為人、跨校事件非管轄校），移轉權責機關並通知當事人 | 性平法第31條 |
| **20 天** | 受理審查 | 性平會議決受理與否，並於 20 日內以書面通知申請人/檢舉人；不受理申復亦為 20 日 | 性平法第32條 |
| **2 個月** | 調查報告完成 | 性平會成立調查小組，於受理日起 2 個月內完成調查報告並提出處置建議 | 性平法第33條 |
| **1 個月 + 1 個月** | 調查展延管制 | 調查程序必要時得延長 1 個月（特殊重大案得依規定展延），最長管制累計約 90 天 | 性平法第33條但書 |
| **30 天** | 申復先行程序 | 當事人對處理結果不服，得於收到書面通知次日起 30 日內向學校提出申復（組審議小組） | 性平法第37條 |
| **30 天** | 循身分救濟 | 對申復結果不服，30 日內依身分向教評申訴會、保訓會、勞基法或學生申訴評議會提起救濟 | 性平法第39條 |

## 🚀 GitHub 上傳與 GitHub Pages 啟用步驟

想要將這個互動資訊網部署至網路上，讓所有同仁與學生以手機隨時查閱，請依照以下步驟操作：

### 步驟 1：建立 GitHub 儲存庫（Repository）
1. 登入 [GitHub](https://github.com/)。
2. 點擊右上角 **「+」** &rarr; 選擇 **「New repository」**。
3. 設定 Repository name（例如：`gender-equity-flow` 或 `campus-gender-event-flow`）。
4. 設定為 **Public**，並點擊 **Create repository**。

### 步驟 2：上傳專案檔案
您可以使用 Git 終端機指令上傳，或直接透過網頁上傳：

#### 方式 A：透過 Git 命令列（推薦）
在專案資料夾內開啟終端機（Terminal / PowerShell），執行：
```bash
git init
git add .
git commit -m "feat: 初版發布 - 性別事件處理流程表互動式資訊網 (114年版)"
git branch -M main
git remote add origin https://github.com/您的帳號/您的儲存庫名稱.git
git push -u origin main
```

#### 方式 B：透過 GitHub 網頁直接上傳
1. 進入剛建立好的 GitHub 儲存庫頁面。
2. 點擊 **「uploading an existing file」**。
3. 將本資料夾中的 `index.html`、`README.md`、`manifest.json` 拖曳上傳。
4. 點擊 **Commit changes** 儲存。

### 步驟 3：開啟 GitHub Pages 免費靜態網頁託管
1. 在您的 GitHub 儲存庫頁面中，點擊上方選單的 **「Settings」**（設定）。
2. 在左側側邊欄找到 **「Pages」**。
3. 在 **「Build and deployment」** 區塊：
   - **Source** 選擇 `Deploy from a branch`。
   - **Branch** 選擇 `main`，資料夾選擇 `/ (root)`。
4. 點擊 **「Save」**。
5. 稍等約 1~2 分鐘重新整理頁面，上方將會顯示您的專屬網站網址：
   `https://<您的GitHub帳號>.github.io/<儲存庫名稱>/`

## 📲 手機端使用建議（PWA 加入主畫面）

- **iPhone / iOS（Safari）**：
  以 Safari 開啟網址 &rarr; 點擊底部分享按鈕（方形帶向上箭頭）&rarr; 選擇 **「加入主畫面」**，即可像原生 App 一樣全螢幕操作。
- **Android（Chrome）**：
  以 Chrome 開啟網址 &rarr; 點擊右上角三個點 &rarr; 選擇 **「加到主畫面」** 或 **「安裝應用程式」**。
